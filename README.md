# 🧬 HealthyLiver

**Прогнозирование исходов заболевания циррозом печени с помощью методов машинного обучения**

---

## 🧠 О проекте

**HealthyLiver** — учебно-исследовательский проект команды **BioMLabs**, созданный в рамках университетской дисциплины УрФУ ИМО «Проектный практикум 1».

**Цель проекта** — разработать интерпретируемую модель машинного обучения для прогнозирования исхода у пациентов с циррозом печени на основе клинико-лабораторных данных.

Проект основан на данных соревнования [Kaggle Playground Series — Season 3, Episode 26](https://www.kaggle.com/competitions/playground-series-s3e26/overview), которое использует синтетический набор данных, смоделированный на основе реальных медицинских наблюдений.

## 🎯 Цели и задачи

- Провести исследовательский анализ данных (EDA) и выявить ключевые закономерности в данных: распределения числовых и категориальных переменных, корреляции, влияние признаков на таргет.
- Провести сравнительное исследование ряда ML-моделей для предсказания исхода заболевания (`C` — жив, `D` — умер).
- Сгенерировать дополнительные признаки в рамках feature engineering и провести отбор наиболее значимых признаков для предиктивной способности модели. 
- Обеспечить **интерпретируемость** результатов (решающие правила/feature importance/SHAP).
